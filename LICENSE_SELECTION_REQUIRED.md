# License selection required before public release

No software license has yet been approved by all authors. Until a license file is added, copyright law reserves reuse rights even if the repository is publicly visible.

Recommended choice: **MIT License** for the original analysis code and documentation. It is short, permissive, and compatible with reproducibility reuse. This recommendation does not license or alter the separate terms governing MIMIC-IV, eICU-CRD, PubMed, ClinicalTrials.gov, or Europe PMC content.

Before making the repository public, the corresponding authors should:

1. approve a code license (recommended: MIT);
2. confirm that all authors agree to public release;
3. add the chosen `LICENSE` file;
4. create the immutable release and archive it (for example, GitHub release linked to Zenodo);
5. insert the resulting URL/DOI in the manuscript data-and-code availability statement.
